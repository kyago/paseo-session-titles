Session Titles renames each chat session after what it is about, so Paseo's own search and history are easy to scan. Paseo names a session after its first prompt ("check the issue below"); this replaces that with a short purpose title.

When a turn finishes, the plugin reads the conversation on the daemon machine and asks Claude Code (Haiku by default, about $0.001 per title) or Codex for a title. It retitles after the 1st and 3rd turns and every 10th after that. A title you set by hand is never changed. Settings → Plugins → this plugin picks the CLI and model (the list comes from the daemon) and how much of the conversation the title model reads (3,000 to 12,000 characters of the user's messages, 5,000 by default). For the first title it also reads the start of the AI's last reply, since a short first prompt rarely says what the session is for. `/retitle` or the Command Center item "세션 제목 다시 짓기" names the current session right away and resumes automatic titles for it.

Requires Paseo 0.12 or later and the Claude Code or Codex CLI, signed in, on the daemon machine. Conversation text comes from Claude Code and Codex transcripts, or from the finished turn for other providers.
